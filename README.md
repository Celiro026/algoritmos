#caso 
El caso representa la carga y descarga de contenedores en un barco mediante una estructura de pila. Cada contenedor se coloca sobre el anterior, por lo que el último en ser cargado será el primero en ser retirado. Se emplean arreglos simples y dinámicos para comparar una capacidad fija con una capacidad que puede aumentar automáticamente.
